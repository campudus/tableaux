# DB-client rewrite keeps the legacy JsonObject result contract

`DatabaseConnection.doMagicQuery` (`src/main/scala/com/campudus/tableaux/database/database.scala`) is the single choke point between the SQL client and all model code: it turns `ResultSet`/`UpdateResult` into a generic `{status, rows, fields, results}` `JsonObject`, which ~189 call sites across ~20 model files consume. When swapping the underlying client to `vertx-pg-client` (`Row`/`RowSet`/`Tuple` API), we keep this JsonObject shape as the boundary rather than pushing `Row`/`RowSet` types up into the model layer. This confines the rewrite to `SQLConnection.scala` + `database.scala` and leaves the 189 call sites untouched, at the cost of not modernizing the model layer's data access style now. Revisit when the deferred JSON-handling modernization happens.
